BESTIE CARD

1. Keep index.html, style.css, script.js and the photos folder together.
2. Double-click index.html to open the card in Chrome/Edge.
3. The four uploaded photos are already inside photos/ as photo1.jpg ... photo4.jpg.
4. No Python or server is required.
5. No music file is required; the sound button uses a tiny browser-generated chime.

To customize the wording:
- Open index.html.
- Search for the text you want to change.
- Save and refresh the browser.

Photo mapping:
photo1.jpg = uploaded together 1
photo2.jpg = uploaded together 3
photo3.jpg = uploaded together 4
photo4.jpg = uploaded together 2 (the WhatsApp/status screenshot)
